# 실제 사용자 검증 프로토콜

Status: 준비 완료 / 참가자 실행 미실시
Updated: 2026-10-29

## 목적

첫 복구 경로가 이해 가능한지, 게임에서 익힌 편집 판단이 실제 Vim 과제로 이어지는지 확인한다. 자동 테스트는 이 실험의 대체물이 아니다.

## 진행

1. 터미널 사용 가능한 Vim 초보/초중급 6~8명을 모집한다. 경험 수준, 기존 Vim 사용 시간을 익명 ID로 기록한다. 진행자는 참여 동의를 받고 화면/입력 기록 범위를 설명한다.
2. 참여자에게 첫 실행 전에 실제 Vim의 과제 A 또는 B를 제공한다. 절반은 A→B, 나머지는 B→A 순서다. 정답 명령은 알려주지 않는다. 기록은 실험 전용 파일에서만 수행한다.
3. 현재 구현 branch를 로컬 실행하고 m → 첫 복구를 선택한다. 진행자 설명 없이 첫 복구까지 걸리는 시간, 막힌 지점, 도움 요청, 오타 복구를 관찰한다. 첫 복구 선택 자체를 찾는 데 걸린 시간도 따로 기록한다.
4. 15~20분 후 반대 과제를 실제 Vim에서 수행한다. 개별 과제 성공, 정상 영역 손상, 도움 요청, 도구를 고른 이유를 기록한다.
5. 추가 작전을 먼저 권하지 않고 참여자가 자발적으로 더 진행하는지 관찰한다. "재밌나요?" 응답만으로 지속 의도를 판정하지 않는다.
6. 동의한 참가자에게 48~72시간 후 새 이름/배치의 유사 과제를 제공한다. 요청받은 후속 테스트와 자발적으로 앱을 다시 실행한 행동을 구별한다. 외부 연락과 일정 설정은 별도 명시적 요청이 있을 때 수행한다.

## 동등 과제 세트

두 세트는 텍스트/정상 영역 보존 조건은 다르지만 같은 검색·단어 이동·값 교체를 평가한다. 평가자가 정답 trace를 강제하지 않는다. 실제 Vim의 다른 정상 풀이도 인정한다.

| 과제 | A | B | 성공 조건 |
|---|---|---|---|
| 신호 위치 찾기 | boot / warn idle / error relay / info end | info ready / alarm pump / warn cache / done | error 또는 alarm 신호의 첫 글자로 이동 |
| 범위 판단 | audit status=down / live status=down / mirror status=up | audit mode=hold / live mode=hold / mirror mode=ready | live 줄의 값만 up 또는 ready로 변경, 다른 줄 보존 |
| 단어 이동 | service api backend enabled | route web gateway active | 첫 글자에서 backend 또는 gateway의 시작으로 이동 |

같은 줄의 token 수, 커서 시작 위치, 글자 수가 다르면 난도 차이가 생길 수 있으므로 파일/커서 위치와 평가 시간을 고정한다. 과제 텍스트는 실제 편집 가능한 실험용 버퍼로 만들고, 위 표와 다른 테스트를 실행했다면 기록한다. 처음부터 모두 풀던 참가자는 천장 효과로 따로 분석한다.

## 기록 양식

| ID | 경험 | 순서 | 사전 성공/3 | 첫 복구 시간 | 막힘/도움 | 사후 성공/3 | 보존 위반 | 자발 추가 | 지연 결과 |
|---|---|---|---|---|---|---|---|---|---|
| 미실시 | | | | | | | | | |

첫 복구 중앙값 5분 이내, 8명 중 6명 이상 설명 없이 완료, 5명 이상 새 과제에서 사전보다 개선하며 도움 없이 성공, 4명 이상 자발 추가를 초기 검토 문턱으로 사용한다. 작은 표본의 의사결정 기준이며 통계적 효과/시장 적합성의 증명은 아니다. 결과가 나올 때까지 수치를 달성했다고 표시하지 않는다.

## 운영 체크

- 설치/실행은 실제 배포본과 개발 branch 중 무엇을 사용했는지 구별한다. 현재 PM 개선은 다음 배포 대상이며 v0.4.0 설치만으로 동일 UI가 제공된다고 안내하지 않는다.
- 사용자의 실제 ~/.advimture 또는 업무 파일을 실험용으로 초기화하지 않는다. 별도 테스트 HOME/작업 폴더를 사용한다.
- 외부 실험 전 자동 단위/E2E gate를 통과시킨다. 중단 시점과 알려진 제한을 기록한다.
